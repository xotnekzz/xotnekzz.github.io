## 다음 사이클 제안

이번 작업 중 발견한 개선 아이디어 (기획 에이전트에게 전달):

1. **카테고리 전용 라우트 추가** (`/category/dev/`, `/category/til/`) — 현재 URL 구조가 `/blog/dev/hello-world/`처럼 카테고리를 포함하나, 카테고리 인덱스 페이지가 없어 탐색이 불완전함
2. **페이지네이션** — 포스트가 늘어날 경우 `/blog/` 페이지에 페이지네이션 필요. 현재는 전체 목록 표시
3. **RSS 피드 제목 확인** — RSS `<item>` 내 `<title>` 이 CDATA 포맷이 아닌 일반 텍스트로 인코딩되어 있을 가능성 있음 (파서 호환성 검토 권장)
4. **`src/content/config.ts` 누락 확인** — `Glob` 결과에서 `src/content/config.ts`가 검색되지 않았으나 빌드가 정상 동작함. Astro 6의 암묵적 Content Collections 지원 여부 확인 권장
5. **`public/images/notion/` 정리** — 이번 사이클 범위 밖으로 명시되었으나, Notion 관련 이미지 파일이 남아있다면 저장소 용량 불필요하게 증가. 다음 사이클에서 정리 권장
