# 보안

## 시크릿

- **절대** 커밋 금지. 환경변수 사용; 필요한 이름은 `README.md`에 문서화
- `.gitignore`가 일반 시크릿 파일 차단; CI가 고-엔트로피 문자열 스캔

## 입력 검증

- 모든 외부 입력은 `runtime` 또는 `ui` 레이어에서 `service` 도달 전 검증
- 서비스는 동일 레이어 그래프 내 호출자를 신뢰

## 의존성 위생

- 락파일 커밋
- 업그레이드는 changelog 리뷰 포함 PR로 제안

## 위협 모델 트리거

다음을 건드릴 때 `docs/design-docs/`에 설계 문서 작성:
- 인증 / 인가
- 암호화 프리미티브
- 신뢰할 수 없는 데이터 역직렬화
- 서브프로세스 / 셸 실행
